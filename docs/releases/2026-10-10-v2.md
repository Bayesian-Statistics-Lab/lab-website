첫 운영 릴리즈 이후 병합한 PR #1~#6을 정리합니다. 기능 기준 커밋 이후 이번 문서와 패키지 메타데이터를 갱신합니다. 이 파일의 존재 자체가 GitHub Release 발행을 뜻하지 않으며 실제 발행 여부는 [Releases 목록](https://github.com/Bayesian-Statistics-Lab/lab-website/releases)에서 확인합니다.

## 주요 변경

### 유지보수 구조

- 논문 공개·선택 삭제 API를 컨트롤러, 서비스, 리포지토리, 엔터티, DTO로 분리했습니다.
- 프론트엔드의 논문 요청 모듈과 공개 상태 표시 컴포넌트를 분리했습니다.
- 기존 관리자 인증·RLS·응답·배치 삭제·부분 성공·캐시 무효화 계약과 호환 어댑터를 유지했습니다.
- 디자인 설정은 `server/theme`·`features/theme`, 이미지 변환과 전송은 `server/media`로 책임을 구분했습니다. 전체 도메인의 리팩토링을 완료한 것은 아닙니다.

### 관리자 디자인 설정

- 배너 오버레이 알파값을 0~100%로 조절하고 미리보기로 확인합니다. 기존 배너 기본값은 100%입니다.
- 블루·포레스트·버건디 추천 테마와 대표·제목·본문·배경·구분 영역 색상 설정을 제공합니다.
- 대비 안내, 저장 전 미리보기, 기본값 복원을 지원합니다.
- 기본 로고·파비콘·모바일 홈 화면 아이콘·연구 카드 SVG 색상을 테마에 연결합니다. 업로드한 사진과 오류·삭제 상태 색상은 유지합니다.
- 상단 브랜드 이름과 아래 문구를 변경합니다. 색상 추천 테마는 문구를 유지하고 기본값 복원은 문구·색상을 함께 복원합니다.

### 연구지원 서식 게시판

- `/support/forms`를 관리자 작성 게시판으로 제공합니다. 목록·상세·번호·작성자·등록일·수정일·15/30/50개 페이지 표시·선택 삭제를 지원합니다.
- 서식 에디터에서 PDF를 최대 10MB까지 첨부합니다. 공개된 서식 본문에 연결된 PDF만 방문자가 다운로드할 수 있습니다.
- 기존 고정 서식 본문은 DB에 보존하며 게시판 화면에서는 표시하지 않습니다. 이전 내용을 옮기려면 관리자가 새 서식 게시글로 등록합니다.
- 서식 상세의 목록 이동과 내 글·관리 화면의 경로를 게시판에 맞게 연결했습니다.

### 이미지·GIF 전송

- 공개 이미지를 같은 출처에서 스트리밍해 브라우저의 Storage 리다이렉트·추가 연결을 줄입니다. 공개 이미지 응답과 참조 인덱스는 60초 캐시합니다. PDF는 기존 리다이렉트를 유지합니다.
- 배너·연구 카드 외에 로그인·구성원 사진도 화면 크기에 맞게 최적화합니다. Next.js 정적 이미지 변환 캐시 최소 TTL은 3600초입니다.
- 계정 메뉴는 96px, 내 프로필은 640px 썸네일을 요청합니다. 비공개 사진은 소유자·관리자 권한을 먼저 검사하고 `private, no-store`로 전달합니다. 변환 캐시가 있어도 접근 검사는 유지합니다.
- 신규 정적 이미지 업로드는 WebP 압축과 일반 사진 1600px·프로필 640px 이내 축소를 적용합니다. 기존 Storage 원본은 수정하지 않습니다.
- 사이트 내 GIF는 960px 애니메이션 WebP로 변환하며 프레임 수·재생 간격·반복 설정을 유지합니다. 3600초 변환 캐시, 동시 동일 요청 공유, 신규 GIF 업로드 후 변환 미리 요청을 적용했습니다.
- GIF 변환은 입력 10MB·120프레임·총 3200만 픽셀·3초 처리·출력 1.4MB 제한을 둡니다. 실패·제한 초과·원본보다 큰 결과는 원본으로 되돌리고 임시 Storage 오류는 실패 결과로 캐시하지 않습니다.

### 메뉴 수정과 기존 기능 보존

- 공지사항 상세 페이지의 왼쪽 메뉴를 글 제목 대신 항상 ‘공지사항’과 목록 링크로 표시합니다.
- 서식 게시판과 이미지 최적화 PR의 페이지 충돌을 해결해 양쪽 기능을 유지했습니다.
- 기존 모바일 반응형, 연·월별 연혁 묶음·최신순 정렬, 가입 승인·계정 삭제·탈퇴, 게시판·갤러리, 교수·구성원·조직도, Scholar 기능은 유지합니다.
- GIF 정지·재생 버튼은 계속 표시하지 않으며 자동 재생과 기기의 모션 감소 설정 반영을 유지합니다.

## 설치·업데이트

1. Node.js 22 이상에서 `npm ci`, `npm run build`로 설치·빌드합니다. 기존 lockfile의 `sharp` 0.35.5를 직접 의존성으로 명시했으며 서버 미디어 변환은 Node 런타임에서 실행합니다.
2. 기존 환경변수·private `lab-media` 설정을 유지합니다. 이번 변경에 추가 환경변수나 DB SQL은 없습니다.
3. 신규 설치는 README의 001~004 SQL 순서를 따릅니다. 기존 계정 삭제·탈퇴에는 004 SQL이 계속 필요합니다.
4. 디자인 설정은 기존 `pages/settings/theme`, 배너 알파값은 기존 배너 설정을 사용합니다. 별도 데이터 변환 작업은 없습니다.

## 검증과 한계

- 병합된 기능 기준과 동일한 Git 트리에서 테스트 **94개**, 타입 검사, 프로덕션 빌드가 통과했습니다.
- GIF 프레임·간격·반복 보존, 이미지 축소·확대 방지, 변환 제한·원본 복귀, 스트리밍·비공개 캐시 정책을 테스트했습니다.
- 실제 운영 이미지의 초기 로딩 시간·개선율과 실제 모바일 기기 화면은 이 결과만으로 검증 완료를 주장하지 않습니다. 첫 변환에는 원본 조회·CPU 처리 시간이 추가되며 변환 제한을 넘는 GIF는 원본을 전송합니다.
- 운영 DB 계정 삭제·탈퇴, PDF 전송·다운로드, 외부 Scholar 전체 흐름은 별도 운영 확인 대상입니다.

## 롤백과 보관

문제가 발생하면 이전 검증 커밋을 다시 배포합니다. 이번 릴리즈에는 DB 마이그레이션과 기존 이미지 원본 변경이 없습니다. 코드 롤백은 이미 삭제한 계정·게시글·논문을 복구하지 않습니다.
